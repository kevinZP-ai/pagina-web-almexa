## Design Specificity Verdict
Moderately generic "dark tech portfolio" template. Domain (warehouse/inventory) is carried only by words, not visuals; a fork-lift/floor-plan motif in the hero or shelf-watermark would anchor it. Competent but domain-unaware.

## Priority Issues
- **P0 — Muted text contrast**: `#8B95A3` on `#1C222A` ≈ 3.7:1, fails WCAG AA (4.5:1). Used in `.desc`, stat labels, `.anexo-desc`, timeline meta. Fix: brighten `--muted` to ≈ `#9DA6B3`+.
- **P0 — No focus indicators**: no `:focus-visible` anywhere; search input sets `outline:none`. Fails WCAG 2.4.7. Fix: global `*:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }`.
- **P1 — 10-link navbar + no back-to-top**: exceeds 5±2 guidance; no scroll-to-top affordance on a 10-section page.
- **P1 — Anexos pill filters lack ARIA**: buttons act as a radio group without `radiogroup`/`aria-checked`/`aria-pressed`.
- **P2 — Tables clipped on mobile without scroll hint** (min-width 640px in overflow-x:auto).
- **P2 — Jargon barrier**: ERF5.9/CU-04.4/DA-08 undefined for first-time judges.
- **P2 — Density without relief**: no charts/data-viz for cost breakdown; four stacked blocks in Calidad.

## Persona Red Flags
- **Jordan (first-timer judge)**: 10-item navbar with no section hints; ERF/RF/DA codes unexplained; 30-card anexos grid requires scrolling everything to find one doc.
- **Casey (mobile)**: 100vh hero pushes CTAs below fold; 11 pills wrap into tall toolbar; tables clip with no scroll affordance; footer has no back-to-top.

## Minor Observations
- Scattered inline `style={{}}` overrides bypass the design system.
- `.badge-medio` reused for both risk "Medio" and validation "Validado" — same teal means different things.
- Anexos `.card:hover` translateY implies the whole card is clickable, but only the button is.
- Hero stripe pattern (0.045 opacity) nearly invisible.
- No `prefers-reduced-motion` guard for pulse/bob/hover transforms.
- "Scroll" text label could be a chevron.
